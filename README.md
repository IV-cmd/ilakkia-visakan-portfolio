# ilakkia-visakan-portfolio

Personal website for Ilakkia Visakan Kanagadhileepan.

## Run locally

```sh
python3 -m http.server 8000
```

Open http://localhost:8000.

## Deploy

This is a static site with no build step. It can be served from any static host, including GitHub Pages from the repository root.

## Content

- Profile, experience, projects, achievements, and contact live in `index.html`.
- Styles are in `assets/css/site.css`; behavior is in `assets/js/site.js`.
- The Writing section is intentionally empty for now.
